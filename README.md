# 📋 Sistema de Gestão de Colaboradores (Java)

Projeto desenvolvido como parte de um trabalho acadêmico da faculdade para praticar os fundamentos da linguagem Java, manipulação de objetos e estruturas de dados.

## 🚀 Funcionalidades
- **Cadastro de Colaboradores:** Permite registrar novos colaboradores informando nome e selecionando o cargo (Júnior, Pleno ou Sênior).
- **Cálculo Salarial Dinâmico:** O sistema calcula automaticamente o salário final com base no salário base de cada cargo somado a uma bonificação.
- **Listagem Dinâmica:** Exibe todos os colaboradores cadastrados utilizando `ArrayList`.
- **Menu Interativo:** Executado via terminal com validações de entrada utilizando laços de repetição (`while`) e estruturas de decisão (`switch-case` / `if-else`).

## 🛠️ Tecnologias Utilizadas
- **Java** (JDK)
- Programação Orientada a Objetos (POO)
- Estruturas de Dados (`ArrayList`)
